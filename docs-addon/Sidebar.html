English Spelling & Thesaurus

Spelling checks look up unique words in DictionaryAPI.dev. Synonym lookups use STANDS4 for one word you enter. Neither feature checks grammar.

STANDS4 credentials

Credentials are stored in your Apps Script user properties. STANDS4 requires the token ID in the request URL. Synonym lookups send only the word entered below.
